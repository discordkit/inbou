Add `/bunpou start`, a JLPT N5 grammar mock test: one question at a time with numbered buttons, private votes, everyone who is right scores, and harder questions are worth more

It ships with 230 hand-written, reviewed items: 155 for 問題1, 61 ★ windows and 15 passages. A passage has eight blanks and a test asks four of them, so a passage that comes up again asks a different set.

Each reveal links the grammar it tested to a Tofugu article, where one covers it, and My results links each missed question the same way.
